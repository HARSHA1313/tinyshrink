✦ TinyShrink — Free Image Compressor

TinyShrink is a simple, free online image compressor that helps you reduce image file sizes directly in your browser.

No account required. No image uploads to a server. Just choose, compress, and download!

✨ Features

- 🖼️ Instant image preview before compression
- 📉 Compress JPG, PNG, and WebP images
- 🎚️ Adjustable compression quality
- 📊 Compare original and compressed file sizes
- 💾 Download your compressed image
- 🔒 Privacy-friendly browser-based processing
- 📱 Simple interface for desktop and mobile
- 🆓 Free to use with no sign-up required

🚀 How to Use

1. Open TinyShrink.
2. Click Choose image and select an image.
3. Preview your selected image.
4. Choose an output format: JPG, WebP, or PNG.
5. Adjust the compression quality.
6. Click Compress image.
7. Review the results and download your compressed image.

🛠️ Built With

- HTML
- CSS
- JavaScript
- HTML Canvas API

🔐 Privacy

Images are processed locally in your browser. They are not uploaded to a TinyShrink server.
